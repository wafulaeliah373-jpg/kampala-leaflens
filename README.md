# LeafLens — Take a closer look outside

LeafLens is a small, privacy-minded plant-spotting demo for curious walks around Kampala. Choose a photo and an open-weight CLIP model compares it with a short list of familiar regional plants. Then ask Gemma to make a tiny outdoor observation quest from the tentative guess. Both models run in the browser with [Transformers.js](https://github.com/huggingface/transformers.js).

## Run it

Because browser modules require a local web server, run:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>. The model files download from Hugging Face on first use; inference happens locally in the browser. The first download needs an internet connection. No image is uploaded by this app.

## What this demo does and does not do

- Accepts a plant photo from camera or file picker, or drag and drop.
- Compares the photo against a shortlist including matooke, coffee, mango, avocado, cassava, maize, jackfruit, and common garden plants.
- Shows the closest matches and their relative comparison scores. These scores are not calibrated probabilities.
- Optionally runs Gemma 3 270M locally to make a short, safe observation quest based on the guess.
- Offers a field observation prompt to encourage a closer look outside.
- Does not identify plants at species level reliably, provide gardening diagnosis, or assess whether something is safe to touch or eat. Confirm any identification with a trusted local source.

## Model and open innovation

Plant matching uses `Xenova/clip-vit-base-patch32`. The optional field quest is generated by `onnx-community/gemma-3-270m-it-ONNX`, a Gemma model, through Transformers.js. Gemma needs WebGPU and downloads only when the user asks for a quest. These open models make it possible to keep the photo and generation on-device and to inspect or replace the model and candidate labels. The shortlist is a prototype, not a locally validated flora dataset. The model downloads are substantial; check the model cards and Gemma terms before reuse.
